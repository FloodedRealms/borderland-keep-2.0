This page will generate both daily and montly weather for ACKS II. For Daily weather, you may use the server random number generator or supply your own dice rolls. The initial weather generated will always be for the Af Climate. If "Simulate weather system" is selected, the server will use the initial dice values supplied. Each subsequent press of the "Fortell!" button will use the previous dice results automatically. In manual mode, you may enter your own values for dice rolls for a given day. The Daily mode will randomly generate a single day, following the weather front rules if selected (you can see the previous day's rolls in the Modifiers section). Monthly mode will generate 31 days of weather, and let you pick an output format. Currently, copyable CSV and Markdown are supported.
